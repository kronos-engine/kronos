A simple spring boot project with spring boot security integrated.

## Description

This project provides a simple CRUD operations performed against NoSQL database. We are using reactive programing here. The project is using hexagonal design pattern, but a simpler version.

## Getting Started

### Dependencies

* Gradle, but we are using Gradle wrapper here.
* Java 21
* MongoDB
* Docker - if you are using mongodb in docker

### Installing

* None in particular

### Executing program

* How to run the program

```
./gradlew clean build
```
